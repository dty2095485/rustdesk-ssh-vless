# 1.5.1.2 — 2026-10-30

Windows and Android clients built on upstream RustDesk **1.5.1** (tag `1.5.1`,
commit `e1ca09766`), fork revision 2.

- Source: `github-release` commit `f35d667`, tag `v1.5.1.2`.
- Base: the published 1.5.0.11 source tree (`791fd6c`), merged with upstream 1.5.1.

## Changes

- Upstream 1.5.1: configurable keyboard shortcuts, signed update-metadata
  verification, trusted-device V2 with legacy upgrade compatibility, address-book
  button for the web console, Android SAF folder transfers, plus fixes across
  DRM/Wayland capture, macOS packaging, Windows installer handoff, WebSocket and
  file transfer.
- Fork features kept: SSH tunnel, VLESS TCP+TLS, VLESS REALITY, JSON network
  profile import/export, and the Windows clipboard high-throughput channel.
- Fixed against 1.5.1.1: the Windows clipboard file owner keeps reading the file
  list its transfer started from, matches requests by `clipDataId`, splits reads
  over 16 MB and refuses oversized requests; these upstream fixes were dropped by
  the 1.5.1.1 merge (see `CHANGELOG.md`, entry `[1.5.1.1] [superseded]`).

- Docker image: the container starts, hbbs/hbbr listen on 21115-21119, the key pair is generated; the archive is the 1.5.1.1 image re-tagged for this version.

## Known limits

- Build-level and unit-test verification only; remote control, file transfer and
  REALITY connectivity were not exercised on real devices.
- The Windows installer is unsigned; the APK uses the fork's debug signing key.
