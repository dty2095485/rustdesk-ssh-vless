我该在哪里配置？

本页面负责“域名 → 端口”。例如 SNI 为 rd.example.com 的流量转到本机 REALITY 入站；匹配后，Nginx 不参与 UUID 认证。RustDesk 与代理上网共用同一个 REALITY 入站时，应在 3x-ui 里按用户分配路由，不需要为每个 UUID 新增入口规则。仅按 ALPN 区分网站与 VLESS 时，客户端声明的 ALPN 必须与规则一致。
